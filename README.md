# 🔐 Password Manager — Landing Page

A modern, fully responsive landing page for a **Password Manager** app. Built with pure HTML, CSS, and JavaScript — no frameworks required. Designed for all screen sizes from small mobile (360px) to 4K ultra-wide displays.

---


## ✨ Features

- ✅ Fully responsive — works on all screen sizes (360px to 2560px+)
- ✅ Dark theme with blue accent color palette
- ✅ Sticky navigation bar with mobile hamburger menu overlay
- ✅ Hero section with headline and shield graphic
- ✅ Features grid — Login, Credit Card, Secure Notes, Identity
- ✅ How It Works — 3-step walkthrough with alternating layout
- ✅ Bento-style Vault gallery section
- ✅ App Download section with App Store & Google Play buttons
- ✅ Testimonials grid with star ratings
- ✅ FAQ accordion with smooth open/close animation
- ✅ Contact form with info panel
- ✅ Footer with logo, links, and copyright

## 📐 Responsive Breakpoints

| Breakpoint | Target |
|---|---|
| `≥ 1920px` | Ultra-wide / 4K displays |
| `≥ 1400px` | Large desktops |
| `1024px – 1400px` | Standard desktops & laptops |
| `768px – 1024px` | Tablets (landscape) |
| `480px – 768px` | Tablets (portrait) & large mobiles |
| `360px – 480px` | Standard mobile phones |
| `≤ 360px` | Small mobiles (Galaxy S series, etc.) |
